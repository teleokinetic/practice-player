Day 3 · resting on power · audio

What does the wanting rest on?

Narration plays, gaps open, you speak, transcripts land below — and export as markdown at the end. Speech windows are always optional.

1 · Key

Your OpenAI key transcribes the gaps. It stays in this browser only (localStorage) — never in the page's code or on any server.

2 · Mic

One-time permission. The mic only opens while you're recording a gap — never during narration or dwells, so speaker playback is fine.

3 · Dwells

Every timer starts at zero — how long do you want this? 0:00 means open: the dwell runs until you tap.

Dwells are silent audio, so they keep running if the screen locks. Speech windows need the screen on.

First run: play ten seconds, tap record, say a line, check the transcript arrives. That smoke test covers everything worth worrying about.
